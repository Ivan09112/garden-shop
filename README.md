# Garden Shop — интернет-магазин садовых товаров

Итоговый проект: React + Redux Toolkit + React Router + React Hook Form.
Вёрстка по макету Figma «Итоговый проект (2024)», данные берутся с `telran-backend`
(исходный код бэкенда не изменялся).

## Запуск

1. Бэкенд (в папке `telran-backend`):

   ```bash
   npm i
   npm run dev
   ```

   API поднимается на `http://localhost:3333`.

2. Фронтенд (в этой папке):

   ```bash
   npm i
   npm run dev
   ```

   Сайт откроется на `http://localhost:5173`.

Сборка для продакшена: `npm run build`.

## Стек

- **React** (сборка Vite)
- **Redux Toolkit** — хранилище: категории, товары, корзина
- **React Router DOM** — маршрутизация
- **React Hook Form** — формы с валидацией
- Запросы к API — встроенный `fetch` (без дополнительных библиотек)

## Страницы

| Путь              | Страница                                                                 |
| ----------------- | ------------------------------------------------------------------------ |
| `/`               | Главная: баннер, 4 категории, форма скидки 5%, 4 случайных товара со скидкой |
| `/categories`     | Все категории                                                            |
| `/categories/:id` | Товары категории + фильтры                                               |
| `/products`       | Все товары + фильтры                                                     |
| `/sales`          | Товары со скидкой + фильтры (без чекбокса скидки)                        |
| `/products/:id`   | Товар: фото, цена, скидка, счётчик количества, описание                  |
| `/cart`           | Корзина: пустая / с товарами / «заказ оформлен» с поп-апом               |
| `*`               | Страница 404                                                             |

## Функциональность

### Фильтры и сортировка

- Цена «от» / «до» (по актуальной цене с учётом скидки).
- Чекбокс «Discounted items» — только товары со скидкой.
- Кастомный выпадающий список сортировки: `by default`, `newest`,
  `price: high-low`, `price: low-high`. Закрывается по клику вне списка.
- Логика вынесена в хук `useProductsFilter` и функцию `filterProducts`.

### Корзина

- Добавление товара из карточки (кнопка появляется при наведении)
  и со страницы товара с выбранным количеством.
- Изменение количества (+ / −), удаление товара, подсчёт суммы и количества.
- Счётчик товаров на иконке корзины в шапке.
- Корзина сохраняется в `localStorage` и не пропадает после перезагрузки.

### Формы (React Hook Form)

- **Скидка 5%** на главной → `POST /sale/send`.
- **Оформление заказа** в корзине → `POST /order/send`
  (имя, телефон, email, список товаров и сумма).
- Валидация имени, телефона и email с сообщениями об ошибках.
- Состояния кнопок после отправки: «Request Submitted», «The Order is Placed».
- После заказа — поп-ап «Congratulations!» (закрывается крестиком, кликом
  по фону или Esc), после закрытия корзина очищается.

### Прочее

- Несуществующая категория или товар → страница 404.
- Индикатор загрузки и сообщение об ошибке, если бэкенд недоступен.
- При переходе между страницами — прокрутка наверх.
- Активный пункт меню подсвечивается зелёным.

## Вёрстка

- Точные значения из Figma: шрифт **Montserrat** (400/500/600/700), размеры,
  отступы, цвета, радиусы скругления.
- Цвета вынесены в CSS-переменные в `index.css`:
  `--green #339933`, `--black #282828`, `--grey #8b8b8b`,
  `--grey-divider #dddddd`, `--light-grey #f1f3f4`.
- Состояния элементов из макета: hover / active для кнопок, меню,
  навигационных кнопок, чекбокса и сортировки; «Added» у кнопки корзины.
- Иконки (логотип, корзина, Instagram, WhatsApp, цифра «4») выгружены из макета в SVG.
- Картинки баннера, формы скидки и страницы 404 — из макета.
- Карта в подвале — встроенная Google Maps (в макете статичная картинка).
- Вёрстка под десктоп (ширина макета 1440px), мобильная версия не делалась.

## Структура

```
src/
  api/          — адрес бэкенда и запросы
  assets/
    icons/      — SVG-иконки
    images/     — картинки из макета
  components/   — компоненты (папка = index.jsx + Имя.module.css)
  hooks/        — useProductsFilter
  pages/        — страницы (папка = index.jsx + Имя.module.css)
  store/        — Redux store и слайсы
    slices/     — categoriesSlice, productsSlice, cartSlice
  utils/        — цены, фильтрация и сортировка, правила валидации
  App.jsx       — маршруты
  main.jsx      — точка входа
  index.css     — шрифты, CSS-переменные, общие стили
```
